# .planning/ — v1 planning archive (read-only)

This directory is the planning record for Phases 1–7 (vendored base through
frontend benchmarks). It was generated by GSD (Get Shit Done)
and is kept as history: phase plans, summaries, research, reviews, verification
reports, and the requirement IDs (`WIRE-01`, `BENCH-01`, `PAR-02`, …) that code
comments still cite.

GSD is retired for this repo. Do not run `/gsd-*` commands or add files here.
New work is tracked as GitHub issues and plan docs under `docs/plans/`.

Do not move or delete this directory: `python/tests/test_parity_report.py`
reads `.planning/STATE.md`.
