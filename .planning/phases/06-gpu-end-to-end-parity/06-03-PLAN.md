<objective>
Write the curated 128-prompt corpus (D-01, D-03) and extend the comparison to full D-05 localization: every mismatch is bisected to the first diverging token and attributed to tokenization/chat template (Phase 4), request mapping (Phase 5), the backend, or detokenization/response building.

Purpose: the zero-tolerance gate (D-04) only helps if a failure points straight at its cause. Ids first (D-06) answers "did the backend see the same input and produce the same output?". The precedence order answers "where did it go wrong first?".

Corpus composition is Claude's discretion per CONTEXT. It uses 128 items, more than the 100-prompt minimum, because 128 is exactly the D-10 concurrency level. The single PAR-02 run then puts the whole corpus in flight at once, and every prompt has both a sequential and a concurrent result to compare.

Output: fixtures/parity/corpus.json, the corpus validation, the full localization in compare.py, and tests.
