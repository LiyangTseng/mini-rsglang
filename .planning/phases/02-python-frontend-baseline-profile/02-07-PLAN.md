<objective>
Ship the GPU-box runbook wrapper, scripts/gpu_phase2_profile.sh. It mirrors scripts/gpu_phase1_check.sh's CLI and PASS/FAIL shape, checks every GPU-only prerequisite before launching anything, and then runs the driver's discover, run and validate subcommands plus the frozen-tree check.

Purpose: ROADMAP criterion 4 asks for the profiling run to be scripted so it can be repeated on the GPU machine. RESEARCH Pitfall 4 says py-spy must attach to already-running sibling processes, which needs CAP_SYS_PTRACE or root on Linux. The preflight probes that ahead of time and explains the least-privilege fixes, instead of failing 10 minutes into a run. The wrapper's helpers are tested on the Mac by sourcing the script, the same way python/tests/test_gpu_check_script.py tests gpu_phase1_check.sh. The real run is plan 02-09's job.
Output: scripts/gpu_phase2_profile.sh and python/tests/test_gpu_profile_script.py.
</objective>
