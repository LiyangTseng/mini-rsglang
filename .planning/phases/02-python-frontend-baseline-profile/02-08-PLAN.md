py-spy flags (Claude's discretion per CONTEXT): `record --nonblocking --rate 100 --format speedscope` per role, plus a second concurrent `--gil` pass. --nonblocking avoids pausing the profiled process, so the latency being measured is not perturbed. The --gil pass yields the per-process GIL-held fraction (RESEARCH Open Question 1). --native is not used: native unwinding needs blocking mode, and the native radix kernel's time is still attributed to its calling Python radix frame. 02-05 records that blind spot.
