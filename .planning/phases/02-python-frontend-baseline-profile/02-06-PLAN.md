Build the three workload drivers the profiling run applies to the server. Scenario 1 is 128 concurrent agents with dynamic cancellations (D-06). Scenario 2 is 32-token short-prompt saturation, adapted from bench_simple.py's helpers (D-07). Scenario 3 is cold start via hyperfine with /v1/models polling and whole-tree PSS (D-08). These drivers produce the request timings that the GC-to-P99 correlation and per-request IPC cost (02-05) depend on, and the cold-start numbers for scenario 3. Scenarios 1 and 3 are tested end to end on the Mac against the 02-03 stand-in server. Scenario 2's real path needs openai, pydantic and a Hugging Face tokenizer, which exist only on the GPU box, so its control flow is tested with fakes injected into sys.modules, and its real imports run on the GPU box.
