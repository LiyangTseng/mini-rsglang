Scenario entry schema this plan enforces. "int" means a non-bool int; "num" means a finite int or float that is not a bool; "?" means the value may be null.
- params: dict (free-form; the run's scenario flags)
- processes: {api_server: int>0, scheduler: int>0, tokenizer: int>0 (the three distinct), other: [int>0]}
- window_s: num >= 0
- requests: {sent: int>=0, completed: int>=0, cancelled: int>=0, failed: int>=0 (the three outcome counts sum to sent), ttft_ms: {p50, p90, p99, max: num>=0 ?}, rps: num>=0 ?}
- gc: for each role, {count: int>=0, by_generation: {"0", "1", "2": int>=0, summing to count}, total_pause_ms: num>=0, pause_ms: {p50, p99, max: num>=0 ?, all null exactly when count == 0}, collected: int>=0, events: [[t_rel_s num, duration_ms num>=0, generation int in 0..2]]}
- gc_ttft_correlation: {frontend: X ?, scheduler: X ?}, where X = {p99_ttft_ms: num>=0 ?, spike_requests: int>=0, spike_with_gc: int (0..spike_requests), nonspike_requests: int>=0, nonspike_with_gc: int (0..nonspike_requests), spike_overlap_rate: num in [0,1] ? (null iff spike_requests == 0), nonspike_overlap_rate: num in [0,1] ? (null iff nonspike_requests == 0)}
- memory: {per_role: for each role {rss_bytes: {start, end, max: int>=0 ?, growth: int ?}, rss_curve: [[t_rel_s num, int>=0]], tracemalloc: {current_start, current_end, peak: int>=0 ?}, tracemalloc_curve: [[t_rel_s num, current int>=0, peak int>=0]], top_alloc_sites: [{file: str, line: int, size_bytes: int>=0, count: int>=0}] ? (at most 10)}, rss_tree_bytes: {ready, end: int>=0 ?}, pss_tree_bytes: {ready, end: int>=0 ?}}
- cpu: for each role, {active_samples: int>=0, gil_samples: int>=0, window_s: num>=0, rate_hz: int>0, cpu_active_pct: num>=0 ?, gil_held_pct: num>=0 ?, buckets: {name: {samples: int>=0 and <= active_samples, share_of_active: num in [0,1] ?, per_request_ms: num>=0 ?}}}. Required bucket names: radix, ipc_zmq, serde, tokenize, detokenize, http_stack, api_handlers.
- radix: {radix_samples: int>=0, scheduler_samples: int>=radix_samples, share: num in [0,1] ? (null iff scheduler_samples == 0)}
- artifacts: {work_dir: str}
- s3_coldstart only: coldstart: {hyperfine: {mean_s, median_s, min_s, max_s: num>=0, stddev_s: num>=0 ?, times_s: [num>=0], runs: int>=1 == len(times_s)}, ready_s_self_timed: [num>=0], rss_tree_bytes_at_ready: [int>=0], pss_tree_bytes_at_ready: [int>=0 ?]}
