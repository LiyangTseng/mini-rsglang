<objective>
Phase tracer: prove the whole discovery and instrumentation pipeline end to end on the Mac with one entry point, `scripts/baseline_profile.py discover`, before any scenario driver, analysis or reporting is built.

Purpose: every later number in BENCH-01 depends on four things working together. (1) The driver owns a race-free top PID (RESEARCH Pattern 1). (2) It can tell the scheduler child from the tokenizer child without OS process titles (Pattern 2, needed by D-09). (3) The 02-02 hook reaches every process (D-02/D-03). (4) A validated JSON sidecar lands on disk (D-13/D-14). This slice wires all four once, against a stand-in server tree that mimics minisgl's exact topology: an exec hop, then a spawn scheduler child and tokenizer child, then uvicorn opening the port only after both acks. Mac tests cannot run the real backend, which is GPU-only, or real py-spy, which needs root on macOS. Both stand-ins are fillable seams: on the GPU box the same code runs with the real `python -m rsglang.launch --frontend python` and the real py-spy, and no code path changes. `discover` stays in the final system as the GPU run's privilege and topology smoke step (02-07 wrapper step 1).
Output: procs.py, sidecar.py, fake_profile_env.py, scripts/baseline_profile.py (discover) and test_baseline_profile.py.
