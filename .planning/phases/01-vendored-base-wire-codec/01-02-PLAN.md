main.rs additions (D-08, D-10, D-11, D-12):
- Exit-code constants: EXIT_OK = 0 (SIGINT/SIGTERM), EXIT_STARTUP = 1 (socket open failure), EXIT_BAD_HANDSHAKE = 2 (malformed, unsupported version, SHA mismatch), EXIT_STDIN_EOF = 3 (launcher went away, before or after the handshake).
- stdin is read on a dedicated std::thread, not tokio::io::stdin (RESEARCH Pattern 5: tokio's stdin is a blocking read that cannot be cancelled and hangs runtime shutdown). The thread iterates std::io::stdin().lock().lines() and sends enum StdinEvent { Line(String), Eof, Error(String) } over a tokio::sync::mpsc::channel(16) with blocking_send, ending with Eof (or Error).
- After "sockets ready", tracing::info!("awaiting handshake on stdin") and run a tokio::select! loop over the stdin channel, tokio::signal::ctrl_c() and the SIGTERM stream:
  - Line: handshake::parse_handshake(&line, handshake::EXPECTED_UPSTREAM_SHA). On Err(e): tracing::error!("handshake rejected: {e}") and exit EXIT_BAD_HANDSHAKE. On Ok(hs): tracing::info!(max_seq_len = hs.max_seq_len, eos_token_id = %hs.eos_display(), page_size = hs.page_size, max_running_req = hs.max_running_req, num_pages = hs.num_pages, upstream_sha = %hs.upstream_sha, "handshake received") and move to the idle phase.
  - Eof or Error before the handshake: tracing::error!("launcher went away (stdin EOF) before handshake") and exit EXIT_STDIN_EOF.
  - SIGINT / SIGTERM: tracing::info!("received SIGINT; exiting") or ("received SIGTERM; exiting") and exit EXIT_OK.
- Idle phase: tracing::info!("idle until SIGINT/SIGTERM or stdin EOF"); select over the same sources. An extra stdin line logs tracing::warn!("ignoring unexpected stdin line"); Eof/Error logs tracing::error!("launcher went away (stdin EOF)") and exits EXIT_STDIN_EOF; signals exit EXIT_OK.
- Exit with std::process::exit so no blocking destructor (zmq context term, stdin thread) can hang shutdown; sockets use linger 0.
- The binary never calls Transport::send_backend in Phase 1: nothing may reach the scheduler before the handshake (D-10), and the skeleton sends nothing at all.
