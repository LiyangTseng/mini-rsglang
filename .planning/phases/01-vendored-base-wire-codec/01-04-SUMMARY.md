# Phase 1 Plan 04: rsg-wire Codec and Golden Fixtures Summary

**rmp-serde (`to_vec_named`) msgpack codec for the 7 scheduler-boundary message types plus the Tensor tag, locked byte-for-byte to 34 golden fixtures generated by upstream's own `serialize_type` + `msgpack.packb(use_bin_type=True)` on the Mac**

## Accomplishments
- `rsg-wire` library crate with no I/O dependencies: internally tagged `BackendMsg`/`TokenizerMsg` enums, `Tensor` (serde_bytes buffer, `torch.int32` dtype, little-endian helpers) and `SamplingParams` (f64 floats, upstream defaults), `WireError` via thiserror, and `UPSTREAM_SHA` read from `vendor/UPSTREAM_SHA` at compile time.
- `scripts/gen_wire_fixtures.py` exports the full D-16 matrix (34 cases) from the vendored `minisgl` classes and writes a readable manifest. `--check` regenerates the fixtures in a temp dir and byte-diffs them against the committed set.
- The Rust tests prove byte equality in both directions for every case: decode then re-encode, and a hand-built value encoded. They also check that the case table matches the manifest order, that `UPSTREAM_SHA`, the manifest and `vendor/UPSTREAM_SHA` hold the same SHA, that every tag has a `base_` case, and that manifest lengths match file sizes.

## Byte-flip check (acceptance criterion, done on scratch copies)
For each test, the repo subset (`crates/rsg-wire`, `fixtures`, `vendor/UPSTREAM_SHA`, the workspace files) was copied to a temp dir, one byte of one fixture was flipped, and both gates were run against the copy. The committed fixtures were not touched.

| Flipped fixture | `--check` | `cargo test --test fixtures` | Failing tests |
|-----------------|-----------|------------------------------|---------------|
| base_abort_backend_msg (last byte, uid 07→06) | exit 1, `DIFF ... bytes differ` | FAILED | hand_built_cases_match_fixtures |
| base_tensor (middle byte) | exit 1 | exit 101 | hand_built_cases_match_fixtures |
| tensor_len_16384 (middle byte) | exit 1 | exit 101 | hand_built_cases_match_fixtures |
| base_sampling_params (middle byte) | exit 1 | exit 101 | every_fixture_roundtrips_byte_exact, hand_built_cases_match_fixtures |
| batch_tokenizer_n (middle byte) | exit 1 | exit 101 | every_fixture_roundtrips_byte_exact, hand_built_cases_match_fixtures |

A flipped value byte still decodes and re-encodes to the same flipped bytes. That is why the hand-built test is needed: the round trip alone cannot catch a symmetric error.

## Decisions Made
- rmp-serde derives were enough. Every fixture matched on the first run, so no `rmpv` fallback was needed for the internally tagged `BatchTokenizerMsg`/`BatchBackendMsg` decode.
- The generator pins its import to the vendored tree. If `minisgl` resolves anywhere else, it exits 2.
- `--check` leaves out the manifest's `generator` versions block, as the plan specified.
