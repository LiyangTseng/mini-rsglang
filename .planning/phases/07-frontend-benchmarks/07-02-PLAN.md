<objective>
Extend Phase 2's in-process hook with the GC-only mode that D-14/D-15 need, plus process-name records that let the harness attribute GC pauses and memory to roles without py-spy. RESEARCH Pitfall 2: `install()` today always starts gc.callbacks and tracemalloc together. Phase 2 measured roughly 3.5x boot overhead with the full instrument set, and D-15 drops tracemalloc and py-spy from timed runs.

Purpose: BENCH-08 needs Python GC pause counts per process role (api_server, tokenizer, scheduler, launcher) during the timed A/B runs (D-16 is per process, as Phase 2's "Inputs to Phase 7" section asks). Without py-spy, the only cheap in-process role signal is the multiprocessing process name upstream assigns: `minisgl-TP{i}-scheduler`, `minisgl-detokenizer-0` and `minisgl-tokenizer-{i}` in python mode, `rsglang-TP{i}-scheduler` in rust mode, and `MainProcess` for the api_server or launcher. The name is set at spawn bootstrap, after sitecustomize has already run. So the flush thread records it lazily, every time it changes.

Output: an extended python/rsglang/profiling/hook.py and the new python/tests/test_hook_gc_only.py.

Decision (RESEARCH Open Question 2 / Assumption A2, Claude's discretion): an env-var toggle on the existing module, not a second shim. `write_shim`, `hook_env`'s PYTHONPATH logic and the chain-load stay unchanged, so Phase 2's BENCH-01 tooling behaves exactly as before.
</objective>

Otherwise it creates `hook-{pid}-{perf_counter_ns}.jsonl`, writes a start record `{"kind":"start","pid","ppid","orig_argv","t":perf_counter(),"wall":time.time(),"clock"}`, appends `_gc_callback`, calls `tracemalloc.start(1)` if not tracing, starts a daemon `_flush_loop(hook_file, interval, profile_dir)` thread and registers an atexit `_final_flush`.

Exceptions are swallowed.
- `hook_env(base_env, *, shim_dir, profile_dir, interval_s)` sets PROFILE_DIR and INTERVAL, and puts shim_dir and then rsglang's parent dir first on PYTHONPATH.
- `load_hook_records(profile_dir) -> HookRecords(by_pid, malformed_lines)`.
- The shim source runs `install()` only when RSGLANG_PROFILE_DIR is set. It is a string constant written verbatim by `write_shim`.
