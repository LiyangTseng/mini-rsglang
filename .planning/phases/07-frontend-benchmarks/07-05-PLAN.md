<interfaces>
Hook record shapes (python/rsglang/profiling/hook.py, extended by 07-02):
- start: `{"kind":"start","pid":int,"ppid":int,"orig_argv":[str],"t":perf_counter float,"wall":time.time float,"clock":str}`. This is the first line of every `hook-<pid>-<ns>.jsonl` file. An exec'd process gets a second file with its own start record.
- gc: `{"kind":"gc","pid":int,"t":perf_counter at GC stop,"duration_s":float,"generation":int,"collected":int,"uncollectable":int}`. The pause interval is (t − duration_s, t).
- proc (gc_only only): `{"kind":"proc","pid":int,"name":str,"t":float,"wall":float}`. Emitted on each change of the multiprocessing process name; the last one wins.
- mem (full mode only): `{"kind":"mem",...}`. In gc_only it must never appear, and its count is the RESEARCH Pitfall 2 warning sign.
- Upstream names: `minisgl-TP{i}-scheduler`, `minisgl-detokenizer-0`, `minisgl-tokenizer-{i}`; rust mode `rsglang-TP{i}-scheduler`; `MainProcess` for the leader.

Phase 2 semantics to port (python/rsglang/profiling/analysis.py, procs.py):
- `percentile(values, p)`: sort, then index `ceil(p/100*n) − 1` clamped, None when empty. `slice_window`: `t0 <= t <= t1`.
- `gc_stats`: count, by_generation keys "0"/"1"/"2", total_pause_ms, pause_ms {p50, p99, max} (all None when empty).
- `gc_ttft_correlation`: requests with t_first only; threshold = percentile(ttfts, 99); spike when ttft >= threshold; overlap when `pause_start < t_first and pause_end > t_send`; output {p99_ttft_ms, spike_requests, spike_with_gc, nonspike_requests, nonspike_with_gc, spike_overlap_rate, nonspike_overlap_rate} (rates None on a zero denominator).
- `tree_memory`: RSS summed over the top pid and its recursive children. PSS only on Linux; on AccessDenied, PSS = None for the whole tree; vanished pids are skipped.
