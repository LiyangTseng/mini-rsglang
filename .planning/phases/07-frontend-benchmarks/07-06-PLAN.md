<objective>
Build the shared A/B orchestrator (D-05, D-06, D-07, D-08), the run manifest, and the first scenario plugged into it: Scenario 1, 128 concurrent agents with random cancellations (BENCH-03). The BENCH-08 observation layer from 07-05 is wired into every trial, so each window's latency numbers come with GC-pause and memory numbers taken during the same run.

Purpose: 07-07 (S2, sweep, cross-checks), 07-08 (S3) and 07-09 (BENCH-06) only add a TrialRunner and a subcommand. Alternation, launch and teardown, observation and manifest writing live here once, as D-08 requires.

Output: the rsg-bench binary (main.rs), cmdline.rs, orchestrator.rs, manifest.rs, scenarios/{mod,s1_cancel}.rs and three test targets.

Interpretation recorded (D-14 with D-15/D-16): "timed runs fully uninstrumented" means no tracemalloc and no py-spy. The lightweight pass runs in the same timed run, alongside it: RSS/PSS is polled from outside the process, and the gc.callbacks hook stays active in-process. D-16's co-occurrence statistic needs GC timestamps and request windows from one run, so a separate run would make it uncomputable. `--gc-hook off` makes a fully hook-free session possible for checking that the hook does not move the numbers.

Pitfall 3: the Python frontend cannot run on the Mac, so the Mac tests here use bench-stub for both arms (an R-vs-R-style mechanics test). They prove alternation, the manifest and the observation wiring, not a comparison.
</objective>
